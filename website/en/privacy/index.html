SpeakLog privacy and data flow: local processing and AI

On-device transcription does not make every feature offline. SpeakLog runs transcription, video rendering and face blurring on the Mac. Cloud AI, visual analysis and external agents can pass relevant content to their providers.

For SpeakLog 0.1.1 · Reviewed October 4, 2026 · 0.1.1 release notes

What runs locally

Speech transcription, video rendering, face detection and blurring, and file export use local Mac processing. A system speech-model download may be needed for a language’s first use.

Imported source media is normally referenced at its existing path; importing does not itself upload the complete file. In-app recordings, project data, exports and sampled analysis frames are written to local files.

What may be sent to AI providers

Review, translation, annotation, blog generation, content analysis, topic generation and assistant chat send the text and context needed by the feature. Cloud routes include Claude Code, Codex CLI and the Anthropic API. A signed-in CLI is not offline processing.

Visual analysis extracts frames from a video, or reads a photo, and passes images to a vision-capable CLI. If the global provider is the Anthropic API or the on-device model, visual analysis still uses Codex CLI. This is more than sending text, but does not mean the complete original video is uploaded.

The on-device model keeps the text tasks it actually handles local. Its selection is not a block on all external calls. The import workflow can review automatically; disable unwanted automatic tasks and check settings before processing sensitive content.

Projects, logs and external agents

The default project library is Movies/SpeakLog on your Mac. AI usage records can contain prompts, raw outputs, model names, token counts and estimated costs. Project packages and logs can therefore contain private material.

MCP communicates with the app locally, but connected external agents can read and change projects. That context may also reach the agent provider. Connect only trusted clients and review their data settings.

The app stores Anthropic API keys in the macOS Keychain. Do not paste keys, project logs or private media into a public issue report.

Costs and control boundaries

Text tasks using the on-device model do not incur cloud API-call charges. Cloud subscriptions, API bills, quotas and retention rules depend on your provider. The app’s cost display is an estimate, not the provider’s final bill.

This page describes version 0.1.1’s feature and data paths. It does not promise third-party retention behavior or announce future app pricing. Review each service’s terms and privacy settings before use.

Analytics on this website

The product website uses Google Analytics 4 for page views and interactions, including page language, package-download clicks, release-page clicks, language changes and FAQ openings. A download-button click is not proof of installation.

The website loads Google’s analytics script, which your browser or content blocker may block. This is separate from recordings and project content processed by the Mac app. Send privacy questions to speaklog@erzhiqian.cc.

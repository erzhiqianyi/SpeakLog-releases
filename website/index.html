为什么做 SpeakLog

学外语最缺的，是开口说。

很多人想先准备好、说对了再开口，结果一直没说。说了的人，说完也就没了：不知道哪里说错，也没留下什么。

01

先说，不打草稿

随手录一段，或者导入已经拍好的 Vlog、口播视频。不用写稿，不用等「准备好」，想到什么就说什么。

02

原始识别与改写分开

保留原始识别结果，把听写纠错与自然表达分开查看。对照原媒体和练习记录，回顾当时的表达与后来做的修改。

03

改好了，就能发

原话加上改好的版本，本身就是一篇真实的学习记录，直接导出成字幕、博客和视频，发到你常用的平台。

怎么用

四步，从一段录音到一份作品。

  1. 说

    把手机录音、Vlog、口播视频拖进窗口，或者直接在应用里按下录音。导入时按原位置引用文件。

  2. 转录

    本机语音识别，带到每个词的时间戳和置信度，按停顿自动切句。处理速度取决于设备、语言和素材。

  3. 校对

    AI 找出听错的地方和不自然的表达，并说明原因。你用键盘逐句采纳、忽略或手动修改。

  4. 发布

    导出字幕、学习博客和字幕视频。三种产出可以按任意顺序做，也可以只做其中一种。

两层字幕

「我说的」和「更自然的说法」，并排放着。

  • 原话只修正机器听错的地方，你说错的语法保留原样，看得出真实水平。
  • 自然说法把不地道的表达改成母语者会说的样子，每处修改都附上分类和原因。
  • 解释用你的母语写，改写的幅度按你的水平（CEFR、JLPT、HSK、TOPIK…）调整。
  • 改完可以照着提词器再读一遍，重新录音自动对齐字幕。
我说的

昨日は友達と新しいカフェを行きました。

更自然的说法

昨日、友達と新しいカフェに行きました。

助词表示去的地方要用「に」或「へ」，「を」用在穿过、离开的场所。
我说的

ケーキがすごいおいしいでした。

更自然的说法

ケーキがすごくおいしかったです。

活用い形容词的过去式是「〜かった」，不能直接接「でした」；修饰形容词时用「すごく」。

三种产出

一次开口，三样可以直接发的东西。

目前只做导出，不自建分享平台。你的内容发到哪里，由你决定。

字幕

按时间轴排好、校对过的字幕。可以保留原话，也可以用改好的版本，还能加上母语翻译做成双语。

  • SRT / VTT / ASS
  • ASS 保留词性颜色和关键词
  • 也可以直接烧进视频

剪映 · Aegisub · Final Cut · YouTube

学习博客

一篇学习笔记：先是正文，再是「我说的 → 更自然的说法」对照、语法点和生词表。可以设置固定栏目和系列编号。

  • Markdown / HTML
  • 复制富文本后粘贴到 note、Medium
  • 按字数拆成 X 串推供复制

note · Medium · X · Obsidian · 静态博客

字幕视频

卡拉 OK 式逐词高亮、按词性上色、带注音和翻译的字幕视频。预览和导出用同一套渲染，看到什么就导出什么。

  • 原视频、纯字幕、换一段画面三种模式
  • 16:9 · 9:16 · 1:1 画幅
  • 剪辑、压缩停顿、路人打码

YouTube · Bilibili · Instagram · 抖音

更多功能

为「说」和「学」准备的细节。

按项目设置练习语言

英语、日语、中文、韩语、法语、西班牙语、德语……每个作品可以单独设置。

按语言标注

日语标假名，中文标拼音，韩语、俄语标罗马字；英语、法语可以只按词性上色。

抽题开口

不知道说什么？抽一个话题，或者让 AI 按你的水平出一批。

边录边出字幕

应用内录音，按下就开始，停下来自动变成一个作品。

AI 助手

用一句话告诉它怎么改字幕、重写博客或整理笔记。每次修改都能整条撤销。

路人打码

在本机识别画面里的人脸，按人选择要不要打码，拍摄者默认不打。

多素材项目

一次导入多个视频和照片，AI 写总体介绍、给素材打星，并分析内容和画面。

外部 Agent

内置 MCP 接口，可以让 Claude Code 或 Codex 直接读写作品、导出视频。

常见问题

你可能想知道的

SpeakLog 支持哪些语言？

练习语言可按项目设置，包括英语、日语、中文、韩语、法语、西班牙语和德语等。实际转录取决于 macOS 语音支持，首次使用可能需要下载模型；解释和翻译语言可单独设置。

我的录音和视频会被上传吗？

转录、渲染、人脸打码和导出在本机进行。云端 AI 功能会发送所需文字与上下文；画面分析会把抽取的帧或照片交给 Claude Code 或 Codex。即使全局选择端侧模型，画面分析仍使用 Codex。处理私人内容前，请检查自动校对和提供方设置。

AI 会改掉我原来说的话吗？

转录结果和自然说法分层保存，校对时可以采纳、忽略或修改建议。不过 AI 助手和外部 Agent 可以编辑字幕等项目内容；分层不代表所有内容不可修改。请保留原媒体，并检查重要改动。

需要什么样的电脑？

当前 0.1.1 安装包需要 Apple silicon Mac（M 系列芯片）及 macOS 26 或更高版本，不支持 Intel Mac。端侧 AI 文字模型还需要 Apple Intelligence 可用。

可以导出哪些格式？

字幕可导出 SRT、VTT、ASS；博客可保存 Markdown、HTML，或复制富文本到 note、Medium，也能拆成 X 串推；视频可导出 16:9、9:16 和 1:1 的 MP4。导出后由你自行上传或发布。

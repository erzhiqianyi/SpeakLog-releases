SpeakLog をつくった理由

語学でいちばん足りないのは、話すこと。

ちゃんと準備して、正しく言えるようになってから話そうとすると、いつまでも話せません。話したとしても、それきり。どこが間違っていたのかも分からず、何も残りません。

01

原稿なしで、まず話す

さっと録音するか、撮影済みの Vlog やトーク動画を読み込むだけ。原稿も「準備ができるまで」待つ必要もありません。

02

話したままの記録が残る

元の認識結果を残し、聞き取りの修正と自然な表現を分けて確認できます。元の素材と練習記録を比べて、そのときの表現や後からの変更を振り返れます。

03

仕上げたら、そのまま投稿

元の発言と直した版のセットは、それ自体がリアルな学習記録。字幕・ブログ・動画として書き出して、いつものプラットフォームへ。

使い方

ひとつの録音から作品まで、4 ステップ。

  1. 話す

    ボイスメモや Vlog、トーク動画をウインドウにドラッグ。アプリで直接録音してもOK。読み込んだファイルは元の場所を参照します。

  2. 文字起こし

    Mac 上の音声認識で、単語ごとのタイムスタンプと確信度付き。間（ま）で自動的に文を区切ります。速度は機器、言語、素材によって異なります。

  3. 校正

    AI が聞き間違いと不自然な表現を理由付きで指摘。キーボードで一文ずつ採用・スキップ・修正できます。

  4. 公開

    字幕・学習ブログ・字幕動画を書き出し。順番は自由で、必要なものだけ作ることもできます。

2 層の字幕

「言ったまま」と「自然な言い方」を、並べて比べる。

  • 言ったままは機械の聞き間違いだけを直します。文法の間違いはそのまま残るので、今の実力が見えます。
  • 自然な言い方は、ネイティブならこう言う、という表現に直します。修正ごとに分類と理由が付きます。
  • 説明は日本語で。書き換えの度合いはレベル（CEFR や JLPT・HSK・TOPIK など）に合わせて調整されます。
  • 直した原稿をプロンプターで読み直して再録音。字幕は自動で揃います。
言ったまま

Yesterday I go to a new café with my friend.

自然な言い方

Yesterday I went to a new café with a friend.

時制「Yesterday」があるので過去形の went に。特定の友達でなければ a friend が自然です。
言ったまま

The cake was so much delicious.

自然な言い方

The cake was really delicious.

強調形容詞を強めるときは really や so を使い、much は使いません。

その他の機能

「話す」と「学ぶ」のための細かな工夫。

作品ごとに練習言語を設定

英語・日本語・中国語・韓国語・フランス語・スペイン語・ドイツ語……作品ごとに設定できます。

言語に合わせた注音

日本語はふりがな、中国語はピンイン、韓国語・ロシア語はローマ字。英語は品詞カラーだけでもOK。

お題で話し始める

話すことが浮かばないときは、お題を引くか、レベルに合わせて AI にまとめて出してもらえます。

録音中に字幕表示

ボタンを押せば録音開始。止めればそのまま作品になります。

AI アシスタント

字幕の修正、ブログの書き直し、ノートの整理をひとことで依頼。変更はいつでも取り消せます。

顔のぼかし

Mac 上で顔を検出し、人ごとにぼかすか選べます。撮影者本人は初期設定でぼかしません。

複数素材のプロジェクト

動画や写真をまとめて読み込むと、AI が全体の紹介を書き、素材を評価し、内容と映像を分析します。

外部エージェント

MCP サーバー内蔵。Claude Code や Codex から作品の読み書きや動画の書き出しができます。

よくある質問

気になること

どの言語に対応していますか？

練習言語は作品ごとに設定でき、英語・日本語・中国語・韓国語・フランス語・スペイン語・ドイツ語などを選べます。文字起こしは macOS の音声対応状況によって異なり、初回はモデルのダウンロードが必要な場合があります。説明・翻訳言語は別に設定できます。

録音や動画はアップロードされますか？

文字起こし、描画、顔のぼかし、書き出しはローカルで行います。クラウド AI には各機能に必要な文字や文脈を送ります。映像分析では抽出フレームや写真を Claude Code または Codex に渡し、全体設定が端末内モデルでも Codex を使います。個人的な素材では自動校正と提供元の設定を確認してください。

AI に元の発言を書き換えられませんか？

文字起こしと自然な表現は別のレイヤーで、提案を採用・スキップ・編集できます。ただし AI アシスタントや外部エージェントは字幕などを編集できるため、すべての項目が変更不能ではありません。元の素材を保管し、大事な変更は確認してください。

動作環境は？

現在の 0.1.1 パッケージは Apple silicon Mac（M シリーズ）と macOS 26 以降が必要で、Intel Mac には対応していません。端末内の文字 AI には Apple Intelligence も必要です。

どの形式で書き出せますか？

字幕は SRT・VTT・ASS、ブログは Markdown・HTML に対応します。リッチテキストを note や Medium に貼り付けたり、X のスレッドに分けたりできます。動画は 16:9・9:16・1:1 の MP4 で、アップロードや投稿は自分で行います。

まず話す。
直すのは、あとで。

話した外国語を、字幕・学習ブログ・単語ハイライト付きの字幕動画に。たどたどしくても大丈夫。SpeakLog が文字に起こし、「自分が言ったこと」と「より自然な言い方」を並べて、一文ずつ仕上げるのを手伝います。

Mac 版を入手 使い方を見る

文字起こし・描画・書き出しはすべて Mac 上で · 英語・日本語・中国語・韓国語などに対応

SpeakLog をつくった理由

語学でいちばん足りないのは、話すこと。

ちゃんと準備して、正しく言えるようになってから話そうとすると、いつまでも話せません。話したとしても、それきり。どこが間違っていたのかも分からず、何も残りません。

01

原稿なしで、まず話す

さっと録音するか、撮影済みの Vlog やトーク動画を読み込むだけ。原稿も「準備ができるまで」待つ必要もありません。

02

話したままの記録が残る

実際に話した内容はずっと残ります。AI の修正は隣の別レイヤーに入るだけ。数か月後に見返せば、自分の成長がはっきり分かります。

03

仕上げたら、そのまま投稿

元の発言と直した版のセットは、それ自体がリアルな学習記録。字幕・ブログ・動画として書き出して、いつものプラットフォームへ。

使い方

ひとつの録音から作品まで、4 ステップ。

  1. 話す

    ボイスメモや Vlog、トーク動画をウインドウにドラッグ。アプリで直接録音してもOK。ファイルはコピーされません。

  2. 文字起こし

    Mac 上の音声認識で、単語ごとのタイムスタンプと確信度付き。間（ま）で自動的に文を区切ります。6 分の動画なら約 1 秒。

  3. 校正

    AI が聞き間違いと不自然な表現を理由付きで指摘。キーボードで一文ずつ採用・スキップ・修正できます。

  4. 公開

    字幕・学習ブログ・字幕動画を書き出し。順番は自由で、必要なものだけ作ることもできます。

2 層の字幕

「言ったまま」と「自然な言い方」を、並べて比べる。

  • 言ったままは機械の聞き間違いだけを直します。文法の間違いはそのまま残るので、今の実力が見えます。
  • 自然な言い方は、ネイティブならこう言う、という表現に直します。修正ごとに分類と理由が付きます。
  • 説明は日本語で。書き換えの度合いはレベル（CEFR や JLPT・HSK・TOPIK など）に合わせて調整されます。
  • 直した原稿をプロンプターで読み直して再録音。字幕は自動で揃います。
言ったまま

Yesterday I go to a new café with my friend.

自然な言い方

Yesterday I went to a new café with a friend.

時制「Yesterday」があるので過去形の went に。特定の友達でなければ a friend が自然です。
言ったまま

The cake was so much delicious.

自然な言い方

The cake was really delicious.

強調形容詞を強めるときは really や so を使い、much は使いません。

その他の機能

「話す」と「学ぶ」のための細かな工夫。

どの言語でも練習

英語・日本語・中国語・韓国語・フランス語・スペイン語・ドイツ語……作品ごとに設定できます。

言語に合わせた注音

日本語はふりがな、中国語はピンイン、韓国語・ロシア語はローマ字。英語は品詞カラーだけでもOK。

お題で話し始める

話すことが浮かばないときは、お題を引くか、レベルに合わせて AI にまとめて出してもらえます。

録音中に字幕表示

ボタンを押せば録音開始。止めればそのまま作品になります。

AI アシスタント

字幕の修正、ブログの書き直し、ノートの整理をひとことで依頼。変更はいつでも取り消せます。

顔のぼかし

Mac 上で顔を検出し、人ごとにぼかすか選べます。撮影者本人は初期設定でぼかしません。

複数素材のプロジェクト

動画や写真をまとめて読み込むと、AI が全体の紹介を書き、素材を評価し、内容と映像を分析します。

外部エージェント

MCP サーバー内蔵。Claude Code や Codex から作品の読み書きや動画の書き出しができます。

プライバシーとローカル処理

声も映像も、あなたの Mac の中に。

文字起こし、動画の描画、顔のぼかし、書き出しはすべてローカルで実行。読み込んだファイルは場所を覚えるだけで、コピーもアップロードもしません。AI は提案するだけで、決めるのはあなた。AI の呼び出しはすべて、モデル・トークン数・概算費用とともに記録されます。

よくある質問

気になること

どの言語に対応していますか？

練習する言語は自由に設定できます。英語・日本語・中国語・韓国語・フランス語・スペイン語・ドイツ語などに対応し、作品ごとに変えることもできます。修正理由や文法の説明、翻訳は日本語など、あなたが読める言語で書かれます。

録音や動画はアップロードされますか？

されません。文字起こし、動画の描画、顔のぼかし、書き出しはすべて Mac 上で行い、読み込んだファイルもコピーしません。AI 校正をオンにしたときだけ、文字起こしのテキストが選んだ AI プロバイダに送られます。オンデバイスモデルを選べば完全にオフラインです。

AI に元の発言を書き換えられませんか？

書き換えられません。話した内容は録音した時点で固定して保存されます。AI の修正は「自然な言い方」という別のレイヤーに理由付きで入り、採用するかどうかはあなたが決めます。

動作環境は？

macOS 26 以降を搭載した Mac が必要です。

どこに投稿できますか？

字幕は SRT・VTT・ASS で書き出せ、CapCut・Aegisub・Final Cut で編集を続けられます。ブログは Markdown・HTML のほか、整形済みリッチテキストとして note や Medium に貼り付けたり、X のスレッドに分割したりできます。動画は 16:9・9:16・1:1 の MP4 で、YouTube・Instagram・TikTok などに投稿できます。

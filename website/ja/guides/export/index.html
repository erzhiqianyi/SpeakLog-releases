SpeakLog 書き出しガイド：字幕・ブログ・MP4

字幕、学習ブログ、動画はそれぞれ独立した成果物です。先に文章を確認してから、投稿先に合う形式を選びます。SpeakLog はファイルの保存やコピー用の内容を用意しますが、自動投稿はしません。

書き出す前に確認

名前、専門用語、字幕の時間、改稿で意味が変わっていないかを確認します。元の発言、自然な言い方、説明言語の翻訳を加えた二言語版から選びます。

私的な会話、映っている人、住所、画面内の文字も確認してください。顔のぼかしだけでは、すべての個人情報を隠せません。

字幕：SRT・VTT・ASS

SRT は一般的な文単位の字幕形式、VTT は Web 動画でよく使われる形式です。品詞カラーやキーワードの装飾を残したい場合は ASS を選べます。実際の表示は再生・編集ソフトに依存します。

対応する編集ソフトや動画サービスへ字幕ファイルを読み込みます。単語ハイライト、注音、配色を映像に固定したい場合は、プレビューを確認して字幕動画を書き出します。

ブログ：ファイルまたはクリップボード

確認した字幕から学習ブログを作り、本文、対照文、文法メモ、語彙を見直します。生成や書き直しには選択した AI プロバイダを使います。

Markdown や HTML はローカル保存や対応する公開手順に使えます。note や Medium ではリッチテキストをコピーして編集画面に貼り付けます。X では番号付きの投稿に分け、一件ずつコピーできます。

コピーしただけでは投稿完了ではありません。投稿先の編集画面で書式が変わる場合があるため、公開前にレイアウト、画像、リンクを確認してください。

動画：プレビューから MP4 へ

元の動画に字幕を付ける、字幕だけの背景にする、別の映像に差し替える、という画面を選べます。16:9、9:16、1:1 の画幅、字幕のレイヤー、注音、翻訳、色を設定します。

カット、間、音声、ぼかしを確認してから MP4 を書き出します。描画は Mac 上で実行され、時間は長さ、解像度、効果、機器によって変わります。

MP4 は自分で投稿先へアップロードします。画幅、長さ、形式の要件は変わることがあるため、投稿先の最新の案内を確認してください。

編集できるプロジェクトも保存

MP4 だけでは字幕の編集状態を完全には戻せません。後で直す可能性があれば、SpeakLog のプロジェクトと参照先の元の素材も保管します。

リリースページでバージョンとチェックサムを確認できます。不具合の報告には、バージョン、出力形式、再現手順を添えてください。私的な映像を公開する必要はありません。

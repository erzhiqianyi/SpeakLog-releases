SpeakLog 入門：Mac で読み込み・文字起こし・校正

SpeakLog は、学習中の言語で話した録音や動画を、振り返れる練習記録にします。最初に設定を確認し、短い素材で文字起こしを試してから、必要な形式で書き出しましょう。

1. インストールと動作環境

現在の公開版は 0.1.1 で、Apple silicon Mac（M シリーズ）と macOS 26 以降が必要です。現在のパッケージは Intel Mac に対応していません。PKG をダウンロードし、インストーラの案内に従ってください。リリースページには DMG と SHA256SUMS もあります。

初めて使う言語では、システムの音声モデルをダウンロードする場合があります。文字起こしできる言語はアプリが確認したシステムの対応状況によります。練習言語に設定できても、必ずオフライン認識できるとは限りません。

2. 言語と AI の設定を先に確認

練習言語、説明言語、学習レベルを設定します。修正理由、翻訳、語句の意味には説明言語が使われます。

読み込み後の AI 自動校正は初期設定でオンです。必要に応じて、読み込む前に「設定 → AI」でオフにしてください。個人的な素材を扱う前に、自動校正とプロバイダを確認してください。まず文字起こしだけ試す場合は自動校正をオフにします。クラウド AI の入力は選択した提供元へ送られます。

初期設定の提供元は Claude Code です。Claude Code や Codex を使う前に、それぞれの CLI をインストールしてログインし、「設定 → AI」のテストボタンで接続を確認してください。Anthropic API には自分の API キーを使います。各提供元とオンデバイスモデルでは利用条件が異なります。端末内モデルには有効な Apple Intelligence と利用可能なモデルが必要です。映像分析は別の CLI 経路を使うため、全体設定を端末内モデルにしても、すべての機能がオフラインになるわけではありません。

3. 録音や動画を読み込む

ホームの読み込み欄でファイルを選ぶか、ウィンドウにドラッグします。複数選ぶと一つのプロジェクトになり、素材ごとに処理結果を保存します。アプリ内では音声を録音できます。動画は別のアプリで撮影してから読み込みます。

読み込んだ元の素材は通常、元の場所を参照します。ファイルや保存先のドライブを利用できる状態にしてください。アプリ内の新しい録音はプロジェクト内に保存されます。まず短い素材で言語と音質を確認すると安心です。

4. 文字を確認してから書き出す

元の音声を聞き、名前や単語の聞き間違い、文の区切りを確認します。その後で自然な言い方と修正理由を比べます。AI の提案にも誤りがあるため、意味が変わっていないか確かめてください。

字幕、ブログ、動画はそれぞれ独立して作れます。書き出しても自動投稿はされません。コピーまたは保存した内容を、投稿先へ自分でアップロードします。

うまく動かないとき

文字起こしでは、対応言語、音声モデルの準備、元のファイルの場所、録音権限を確認します。AI では、まず設定画面のテスト機能でプロバイダの動作を確認してください。

処理時間はチップ、素材の長さ、言語、モデルの状態によって変わります。開発中の単発の測定値を一般的な速度保証としては扱っていません。

SpeakLog のプライバシー：ローカル処理と AI のデータ経路

Google / YouTube ユーザーデータのプライバシーポリシー

更新日：2026年10月17日。SpeakLog の任意の Google OAuth 接続と YouTube 公開機能に適用します。SpeakLog はネイティブ macOS アプリです。接続とアップロードは利用者が選択します。開発者は Google / YouTube ユーザーデータを収集・保存するサーバーを運営していません。

1. アクセスする Google ユーザーデータ

認可後、Google は OAuth アクセストークンと更新トークンをアプリに提供します。YouTube Data API から選択したチャンネルの ID とプロフィール snippet（名前、説明、サムネイル URL などを含む場合があります）を受け取り、そのうち ID と名前だけを利用・保存します。公開時は選択した動画、タイトル、説明、公開範囲、任意のサムネイル、字幕とその言語を処理し、アップロードセッション URL、進捗、新しい動画 ID を受け取ります。動画と字幕の元データはローカルの作品であり、既存の YouTube 動画をダウンロードしません。

要求するスコープは https://www.googleapis.com/auth/youtube.force-ssl です。Google は動画、評価、コメント、字幕の表示・編集・削除を可能にする権限として説明していますが、SpeakLog はチャンネル確認と動画・サムネイル・独立字幕のアップロードに使用します。評価やコメントを読み取らず、動画の削除機能も提供しません。アップロード専用の狭いスコープでは独立字幕をアップロードできません。Gmail、連絡先、カレンダー、Google Drive ファイル、Google パスワードへのアクセスは要求しません。

2. Google ユーザーデータの利用目的

チャンネル ID と名前は公開先の表示・確認、トークンは依頼された接続・公開操作の認証に使用します。動画、字幕、メタデータ、サムネイルは選択された YouTube アップロードにのみ使用します。セッションと公開記録は再開、重複アップロードの防止、結果へのアクセスに使います。公開は確認後に開始し、実行中はバックグラウンドで続く場合があります。Google / YouTube API データを販売、広告、プロファイリング、信用判断、AI / ML モデルの開発・改善・学習には使用しません。

3. 共有・転送・開示

YouTube 連携は認可要求と資格情報を Google OAuth サービスへ、選択した公開内容と必要な認可を Mac から Google / YouTube API へ直接送ります。開発者のバックエンドは経由しません。受領した情報は Google / YouTube が Google プライバシーポリシーに従って処理します。視聴できる対象は選択した公開範囲と YouTube の処理・プラットフォーム規則によって決まります。

YouTube 連携は Google トークン、チャンネル資料、公開記録を AI 提供元、広告・アクセス解析サービス、データ仲介業者へ送信しません。開発者も別途これらを受領・共有・開示しません。任意の別の AI 機能による作品データ処理は下記を参照してください。作品パッケージの共有・書き出しや外部エージェントの読み取りを利用者が許可した場合、受領者はパッケージ内のローカル公開記録にアクセスできる場合があります。秘密にしたい情報を含むパッケージは共有しないでください。ウェブサイトのアクセス解析はアプリと別で、この連携から OAuth トークンやチャンネルデータを受け取りません。

4. データ保護

リモートの OAuth と YouTube API 通信は HTTPS / TLS で暗号化します。Google ログインはシステムブラウザーで行い、SpeakLog は Google パスワードを受け取りません。OAuth は PKCE とランダムな state を使い、認可コールバックは Mac の loopback アドレスのみで待ち受け、ネットワークへ公開しません。更新トークンとチャンネル ID・名前は macOS Keychain に保存し、OS の資格情報保護を利用します。短期アクセストークンはアプリのメモリーにキャッシュし、作品ファイルに意図的に保存しません。再開用アップロード記録は所有者のみ読み書きできる権限（0600）で作成します。他の作品ファイルは通常の macOS ファイル権限を使用し、パッケージ全体をアプリ独自に暗号化しません。Mac、バックアップ、共有フォルダーへのアクセスを保護してください。

5. 保存期間と削除

Keychain の更新トークンとチャンネル情報は後の公開に使うため、接続解除または接続の置き換えまで Mac に残ります。このローカル記録に固定の自動削除期限はありません。短期アクセストークンは有効期間内で使用し、更新時にキャッシュを置き換え、接続解除やアプリ終了時にメモリーから消去します。「設定 → YouTube → Disconnect」で保存したローカル認可とアクセストークンのキャッシュを削除できます。Google アカウントの接続管理でも Google 側の権限を取り消せますが、これだけでローカル作品ファイルは削除されません。

未完了セッションは完了またはローカルセッションの破棄まで保持し、成功後は待機記録を削除します。書き出した動画・サムネイル、公開・履歴記録（動画 ID、タイトル、要求した公開範囲、日時）は作品またはファイルを削除するまで保存し、自動保存期限はありません。SpeakLog の作品削除は macOS のゴミ箱へ移動します。完全に削除するにはゴミ箱を空にし、別に作成した書き出し、共有コピー、バックアップも削除してください。接続解除やローカル削除は YouTube 上の内容を削除しません。動画・字幕などは YouTube Studio で管理・削除してください。Google が保持するコピーには Google の保存・削除規則が適用されます。

プライバシーや削除の相談は speaklog@erzhiqian.cc へ連絡してください。開発者は Mac にのみ存在するファイルを遠隔消去したり、利用者の YouTube 動画を代わりに削除したりできません。上記の操作をご利用ください。

Google API から得た情報の利用・転送は、Limited Use 要件を含む Google API Services User Data Policy に従います。YouTube 公開には YouTube 利用規約も適用されます。

Mac 上で処理すること

音声の文字起こし、動画描画、顔の検出とぼかし、ファイルの書き出しはローカルで処理します。言語の初回利用時には、システムの音声モデルをダウンロードする場合があります。

読み込んだ元の素材は通常、元の場所を参照し、読み込みだけでファイル全体をアップロードするわけではありません。アプリ内の録音、プロジェクト、出力、分析用の抽出画像はローカルに保存されます。

AI 提供元へ渡る可能性がある内容

校正、翻訳、注釈、ブログ生成、内容分析、お題生成、アシスタントとの会話では、機能に必要な文字や文脈を渡します。クラウドの経路には Claude Code、Codex CLI、Anthropic API があります。CLI にログインしていることは、オフライン処理を意味しません。

映像分析では動画からフレームを抽出するか、写真を読み取り、画像対応の CLI へ渡します。全体のプロバイダを Anthropic API または端末内モデルにしていても、映像分析は Codex CLI を使います。文字だけの送信ではありませんが、元の動画全体をアップロードすることと同じではありません。

端末内モデルでローカルに処理されるのは、そのモデルが担当する文字タスクです。選択しても外部呼び出しを一律に止めるわけではありません。読み込み後の自動校正もあるため、機微な内容では不要な自動処理を切り、設定を確認してください。

プロジェクト、ログ、外部エージェント

標準の保存先は Mac の Movies/SpeakLog です。AI の利用記録には、プロンプト、元の出力、モデル、トークン数、概算費用が含まれる場合があります。プロジェクトやログにも私的な内容が残り得ます。

MCP はアプリとローカルで通信しますが、接続した外部エージェントはプロジェクトを読み書きできます。その文脈がエージェントの提供元へ送られる場合もあります。信頼できるクライアントだけ接続し、データ設定を確認してください。

Anthropic API キーは macOS のキーチェーンに保存します。キー、プロジェクトのログ、私的な素材を公開の不具合報告に貼らないでください。

料金と制御の範囲

端末内モデルが処理する文字タスクにはクラウド API 呼び出し料金は発生しません。クラウドの契約、API 料金、利用枠、データ保存規則は提供元によります。アプリの費用表示は概算で、提供元の最終請求額ではありません。

このページは 0.1.1 の機能とデータ経路を説明するものです。第三者の保存方針を保証したり、今後のアプリ価格を発表したりするものではありません。各サービスの規約とプライバシー設定を確認してください。

このサイトのアクセス解析

製品サイトでは Google Analytics 4 を使い、閲覧と操作を計測します。ページ言語、インストーラのクリック、リリースページへの移動、言語切り替え、FAQ の展開などが対象です。ダウンロードのクリックはインストール完了を意味しません。

サイトは Google の解析スクリプトを読み込みますが、ブラウザやコンテンツブロッカーが止める場合があります。Mac アプリの録音やプロジェクト処理とは別のデータ経路です。お問い合わせは speaklog@erzhiqian.cc へお願いします。

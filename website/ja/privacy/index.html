SpeakLog のプライバシー：ローカル処理と AI のデータ経路

文字起こしが端末内で動いても、すべての機能がオフラインとは限りません。SpeakLog の文字起こし、動画描画、顔のぼかしは Mac 上で動きます。クラウド AI、映像分析、外部エージェントは、関連する内容を各提供元へ渡す場合があります。

Mac 上で処理すること

音声の文字起こし、動画描画、顔の検出とぼかし、ファイルの書き出しはローカルで処理します。言語の初回利用時には、システムの音声モデルをダウンロードする場合があります。

読み込んだ元の素材は通常、元の場所を参照し、読み込みだけでファイル全体をアップロードするわけではありません。アプリ内の録音、プロジェクト、出力、分析用の抽出画像はローカルに保存されます。

AI 提供元へ渡る可能性がある内容

校正、翻訳、注釈、ブログ生成、内容分析、お題生成、アシスタントとの会話では、機能に必要な文字や文脈を渡します。クラウドの経路には Claude Code、Codex CLI、Anthropic API があります。CLI にログインしていることは、オフライン処理を意味しません。

映像分析では動画からフレームを抽出するか、写真を読み取り、画像対応の CLI へ渡します。全体のプロバイダを Anthropic API または端末内モデルにしていても、映像分析は Codex CLI を使います。文字だけの送信ではありませんが、元の動画全体をアップロードすることと同じではありません。

端末内モデルでローカルに処理されるのは、そのモデルが担当する文字タスクです。選択しても外部呼び出しを一律に止めるわけではありません。読み込み後の自動校正もあるため、機微な内容では不要な自動処理を切り、設定を確認してください。

プロジェクト、ログ、外部エージェント

標準の保存先は Mac の Movies/SpeakLog です。AI の利用記録には、プロンプト、元の出力、モデル、トークン数、概算費用が含まれる場合があります。プロジェクトやログにも私的な内容が残り得ます。

MCP はアプリとローカルで通信しますが、接続した外部エージェントはプロジェクトを読み書きできます。その文脈がエージェントの提供元へ送られる場合もあります。信頼できるクライアントだけ接続し、データ設定を確認してください。

Anthropic API キーは macOS のキーチェーンに保存します。キー、プロジェクトのログ、私的な素材を公開の不具合報告に貼らないでください。

料金と制御の範囲

端末内モデルが処理する文字タスクにはクラウド API 呼び出し料金は発生しません。クラウドの契約、API 料金、利用枠、データ保存規則は提供元によります。アプリの費用表示は概算で、提供元の最終請求額ではありません。

このページは 0.1.1 の機能とデータ経路を説明するものです。第三者の保存方針を保証したり、今後のアプリ価格を発表したりするものではありません。各サービスの規約とプライバシー設定を確認してください。

このサイトのアクセス解析

製品サイトでは Google Analytics 4 を使い、閲覧と操作を計測します。ページ言語、インストーラのクリック、リリースページへの移動、言語切り替え、FAQ の展開などが対象です。ダウンロードのクリックはインストール完了を意味しません。

サイトは Google の解析スクリプトを読み込みますが、ブラウザやコンテンツブロッカーが止める場合があります。Mac アプリの録音やプロジェクト処理とは別のデータ経路です。お問い合わせは speaklog@erzhiqian.cc へお願いします。

SpeakLog 导出指南：SRT 字幕、博客和 MP4

字幕、学习博客和视频是独立的产出。先完成文字审阅，再按目标平台选择格式；SpeakLog 保存文件或准备可复制内容，不会替你自动发布。

适用于 SpeakLog 0.1.1 · 内容核对：2026-10-04 · 0.1.1 发布说明

  1. 导出前先确认
  2. 字幕：SRT、VTT 或 ASS
  3. 博客：文件或剪贴板
  4. 视频：先预览，再导出 MP4
  5. 留一份可继续编辑的项目

导出前先确认

核对姓名、专有名词、时间轴及 AI 改写是否保留原意。确定使用原话、自然说法，还是加上解释语言翻译的双语版本。

导出前检查私人对话、画面中的人、地址和可见文字。人脸打码不能代替逐段检查，也不会处理所有类型的敏感信息。

字幕：SRT、VTT 或 ASS

SRT 是常用的按句字幕格式；VTT 常用于网页视频；需要保留词性颜色和关键词样式时，可选择 ASS。实际显示效果仍取决于播放或编辑软件。

把字幕文件导入支持该格式的编辑器或视频平台。需要逐词高亮、注音和配色固定显示在成片里时，使用字幕视频导出，并先看预览。

博客：文件或剪贴板

基于确认后的字幕生成学习博客，再检查正文、原句对照、语法点和词汇。生成与重写会使用选择的 AI 提供方。

Markdown 和 HTML 适合保存到本地或放进支持它们的发布流程。面向 note 或 Medium，可以复制富文本后粘贴到编辑器；X 可以按长度拆成带编号的串推，逐条复制。

复制不等于发布成功。目标平台的编辑器可能调整样式，请在发布前检查排版、图片和链接。

视频：先预览，再导出 MP4

按素材选择原视频加字幕、纯字幕画面或替换视频画面。设置 16:9、9:16 或 1:1，以及字幕层、注音、翻译和颜色。

检查剪辑、停顿、声音和打码效果，确认预览后导出 MP4。视频渲染在 Mac 上执行；耗时随片长、分辨率、效果和硬件变化。

MP4 可以手动上传到视频平台。平台的画幅、时长和编码要求会变化，最终以目标平台的上传检查为准。

留一份可继续编辑的项目

仅保存 MP4 无法恢复完整的字幕编辑状态。需要以后继续修改时，也保留 SpeakLog 项目和它引用的原始媒体。

发布页提供应用版本和校验文件；如果遇到导出问题，报告应用版本、目标格式和可复现步骤即可，不必公开私人素材。

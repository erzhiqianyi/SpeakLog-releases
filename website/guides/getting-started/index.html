SpeakLog 入门：在 Mac 上导入、转录和校对

SpeakLog 把一段外语录音或视频变成可以回顾的练习记录。先确认设置，再导入一小段素材，检查转录，最后选择要导出的内容。

适用于 SpeakLog 0.1.1 · 内容核对：2026-10-04 · 0.1.1 发布说明

  1. 安装并确认系统要求
  2. 先检查语言与 AI 设置
  3. 导入一段录音或视频
  4. 检查文字，再选择产出
  5. 遇到问题时

1. 安装并确认系统要求

当前公开版本为 0.1.1，需要 Apple silicon Mac（M 系列芯片）及 macOS 26 或更新版本；当前安装包不支持 Intel Mac。下载 PKG 后按安装器提示操作；DMG 和各版本的 SHA256SUMS 校验文件在发布页。

首次转录某种语言时，系统可能需要下载语音模型。实际可转录的语言以应用检测到的系统支持情况为准；练习语言可设置，不代表所有语言都能离线识别。

2. 先检查语言与 AI 设置

设置练习语言、解释语言和学习水平。解释语言决定修正理由、翻译和词汇释义使用什么语言。

导入后的 AI 校对默认开启，可在「设置 → AI」关闭「转录完自动让 AI 校对」。处理私人素材前，请先检查自动校对及提供方设置；只想先转录时，关闭自动校对。云端 AI 的输入会交给所选提供方。

默认提供方是 Claude Code。使用 Claude Code 或 Codex 前，需要先安装相应 CLI 并登录；可在「设置 → AI」用测试按钮检查连接。Anthropic API 使用你自己的 API 密钥。Claude Code、Codex CLI、Anthropic API 和端侧模型的可用条件不同。端侧模型需要 Apple Intelligence 已启用且模型可用；画面分析有独立的 CLI 调用路径，不能只凭全局选择端侧模型就认定整个应用离线。

3. 导入一段录音或视频

通过首页导入入口选择文件，或把文件拖入窗口。一次选多个文件会组成一个项目，每个媒体分别保存处理结果。也可以在应用里录音；录视频请先使用其他工具拍摄，再导入。

导入的原媒体通常按原位置引用。请保留文件和可用的磁盘路径；应用内新录音保存在项目中。先用一段短素材确认语言和音质，比直接处理长视频更容易排查问题。

4. 检查文字，再选择产出

先听原音频，修正机器听错的名字、词语和断句；再查看自然说法及修改原因。AI 建议可能不准确，采纳前请核对意思。

字幕、博客和视频可以分别制作。不要把完成导出等同于已经发布：复制或保存内容后，需要你自行上传到目标平台。

遇到问题时

转录失败时检查系统语音支持、模型是否下载完成、文件是否仍在原位置，以及录音授权。AI 失败时先用设置页的测试功能检查当前提供方。

速度随芯片、素材时长、语言及模型状态变化。本站不把单次测试速度当作通用性能保证。
